Policy (stateful for this scenario)

      

        The first request for a given document always requires the resource owner's explicit
        confirmation. Once granted, the authorization server remembers — later requests for that
        same document are issued a token immediately, with no deferral at all. A different,
        never-requested document starts the review over again.
